# TOHOシネマズ新宿｜新宿映画館サミット2026 リレートーク用プレゼン

`TOHO_Shinjuku_Summit2026.html` をダブルクリックするだけで、ブラウザ（Chrome／Edge 推奨）で開けます。
写真・フォント・動きはすべてこの1ファイルに入っているので、**インターネットがない会場PCでもそのまま動きます**。

| ファイル | 内容 |
|---|---|
| `TOHO_Shinjuku_Summit2026.html` | 本番用プレゼン（これだけ持っていけばOK） |
| `TOHO_Shinjuku_Summit2026_台本.txt` | 台本（読み上げ原稿・クリック位置・目標秒数・要確認メモ） |
| `src/` | 編集用の元データ（HTML／CSS／JS／写真） |
| `script.json` | 台本の元データ |

## 本番の操作

| 操作 | 動作 |
|---|---|
| 画面下の **次へ ›** ボタン ／ → ／ Space ／ PageDown | 次へ（ページの中の動きも1段ずつ進む） |
| 画面下の **‹** ボタン ／ ← ／ PageUp | 前へ |
| 画面下の **●**（ページの点） | そのページへ移動（点にマウスを乗せるとページ名が出ます） |
| 数字 → Enter | その番号のページへ移動（例：8 Enter で 08） |
| F ／ F5 | 全画面 |
| S | 発表者ビュー（台本・経過時間・ペース・次のページ・読み方のメモ）を別ウィンドウで開く |
| N | 台本を画面下に表示（1画面でのリハーサル用） |
| D | 台本を印刷用に開く |
| O | 目次 |
| B ／ . | 暗転（もう一度押すか「次へ」で解除） |
| T | タイマーをリセット |
| M | 動きを控えめにする／戻す |
| ? | 操作一覧 |

- 縦スクロールはありません。1ページずつボタンで切り替わります。スライドをクリックしてもページは進まないので、ページ内の仕掛け（10 LEGACY のつまみのドラッグ、11 のネットワークの点のクリックなど）を安心して触れます。
- ボタンはマウスを動かすと出てきて、2.5秒動かさないと消えます。キーボードやリモコンを使うと、すぐに消えます。
- プレゼン用リモコン（PageUp／PageDown を送るタイプ）でそのまま操作できます。
- 開くと待機画面が出ます。**START** か → でフィルムのカウントダウン（3・2・1）が流れ、表紙が出たら話し始めます。タイマーは表紙が出たときに始まり、Home で待機画面に戻すとリセットされます。
- 画面の大きさ・比率が違っても、16:9 の画面が自動で拡大縮小されます。

## 2画面（プロジェクター＋手元PC）で使うとき

1. Windows は `Win`＋`P` で **拡張** を選ぶ（「複製」だと発表者ビューが客席にも映ります）。
2. このHTMLを Chrome か Edge で開き、ウィンドウをプロジェクター側へ移動して `F` で全画面。
3. `S` で発表者ビューを開き、手元の画面へ移動。発表者ビューのボタンやキーでも進められます。

## ページごとの仕掛け

| ページ | 仕掛け |

| 04 REBIRTH | 写真がせり上がり、ゴジラが吠えて揺れる |
| 05 POSITION | 数字が回転式メーターのように回る、「日本トップシェア」に光が走る |
| 06–07 | 年表の4つの点が飛んで、ポジショニングマップに変形 |
| 08 STRENGTHS | カードがマウスに合わせて3Dで傾く、IMAXの12chイコライザー、MX4Dの揺れと風、ATMOSの音の波紋 |
| 09 RENEWAL | 行列が詰まる様子（イメージ）→ リニューアルで流れる |
| 10 LEGACY | 昔（白黒）と今をつまみのドラッグで比べられる |
| 11 TOGETHER | 点にマウスを乗せると光り、クリックすると光が走る。最後は10ページの「昔／今」の画面が半分開いた状態から左へ全部開き、ゴジラが全面に出て火の粉が舞うエンディング |
| 全ページ共通 | カメラがゆっくりズームアップ／ズームアウト（ページごとに向きが交互）。要所の一言（100万人超、「この街に人を呼び続ける」へ、日本トップシェア、変わらない使命、新宿映画圏を、ともに。）はズームで打ち込むように登場 |
