# リクルート判定システム（TOHOシネマズ新宿版）

アルバイト採用の判断基準を統一するための判定アプリです。
水戸内原版 ver4.4 をベースに、**面接後の採用可否判定を中核**に据え、面接前は「面接者への留意点の申し送り」として再設計しました。
劇場固有のルールはすべて「劇場プロファイル」に切り出してあり、設定画面から編集・JSON で持ち運びできます。

## 使い方（配布）

1. `dist/toho-recruit-judge.html` を PC に置き、ブラウザ（Edge / Chrome）で開く
2. 「応募者判定」で 4 ステップを進める
   1. 応募情報（採用担当が入力）
   2. 面接者への申し送り（留意点を自動生成 → チェック・コピーして共有）
   3. 面接評価（面接者が採点）
   4. 採用可否判定（得点率で 採用推奨 / 上長最終判断要 / 不採用推奨）
3. 「保存（HTML）」で応募者ごとに 1 ファイル保存。レポートとして読め、「読み込み」で再開できる
4. 「設定（劇場ルール）」で文言・しきい値・評価項目を編集。他劇場へは JSON を書き出して展開

設定はブラウザの localStorage に保存されます。応募者データはブラウザに残りません（保存した HTML のみが記録です）。

## 開発

```
recruit-system/
  src/
    index.html          画面骨格
    styles.css          デザイントークン・レイアウト・ダークモード・印刷
    util.js             共通ユーティリティ（パス操作・テンプレート置換）
    config.default.js   劇場プロファイル既定値（新宿）＝ 選択肢・しきい値・留意点ルール・評価項目・文言
    rules.js            判定エンジン（DOM 非依存の純関数）
    storage.js          HTML 保存・読込（JSON 埋め込み方式）、プロファイル保存
    settings.js         設定画面（data-bind によるプロファイル編集）
    app.js              画面制御（ステップ遷移・フォーム生成・右サマリー）
  build.js              src を 1 ファイルに結合 → dist/toho-recruit-judge.html
  dist/                 配布用（ビルド成果物。コミットする）
  tests/e2e.js          Playwright による通しテスト
  docs/HANDOFF.md       詳細ロジックを詰める際の引き継ぎメモ
  docs/reference/       旧版（水戸内原 ver4.4）の参照用コピー
```

- 開発中は `src/index.html` を直接ブラウザで開いても動きます
- 配布ファイルの生成: `node build.js`
- 通しテスト: `node tests/e2e.js`（Playwright + Chromium が必要）

## 設計方針

- **ロジックとルールの分離**: `rules.js` は劇場名・しきい値・文言を一切持たず、`profile` を引数に受け取る
- **留意点ルール** = `rules.js` の `CONDITIONS[id]`（条件）＋ `profile.handoffRules[]`（ON/OFF・重要度・文言）
  - 重要度: `block` 要判断（採用担当が面接実施可否を判断）/ `warn` 要確認（面接時に確認）/ `info` 共有
- **採用可否判定** = 面接評価の得点率（%）で判定。項目数を変えても閾値を調整しなくてよい
- **保存形式** = 人が読める HTML レポート＋ `<script type="application/json" id="recruit-record">` に元データを埋め込み。見た目を変えても読込が壊れない
