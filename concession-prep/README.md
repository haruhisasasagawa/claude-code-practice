# コンセッション事前準備数ツール（雛形）

TOHOシネマズ新宿のコンセッション（飲食売店）向けに、ピーク前の商品準備数（仕込み数）を
過去の購買率から算出するExcelツールの雛形です。

- 成果物: `TOHO新宿_コンセッション準備数ツール.xlsx`
- 生成スクリプト: `build_tool.py`（openpyxl。レイアウトや商品サンプルを変えて再生成できます）
- 検証スクリプト: `verify_tool.py`（サンプルデータから期待値を再計算し、Excelの計算結果と突合）

## シート構成

| シート | 役割 | 主な操作者 |
|---|---|---|
| 使い方 | 3ステップの利用ガイド・凡例・注意点 | 全員 |
| 準備数計算 | 参照期間（直近7日間/3日間/昨日）の購買率 × 予測動員数 × 時間帯倍率 | 社員（確認: スタッフ） |
| 日別データ | 直近7日の日付・動員数を入力。商品別販売数はCSVから自動集計 | 社員 |
| CSV貼付 | 集計ソフトから抽出したCSVの貼り付け場所（商品名一致チェック付き） | 社員 |

## 計算ロジック

- 購買率 ＝ 参照期間の販売数 ÷ 参照期間の動員数
- 準備数 ＝ 予測動員数 × 購買率 × 時間帯倍率（小数点以下切り上げ）
- 時間帯倍率は3枠（例: 通常帯×100% / 混雑帯×120% / ピーク帯×150%）。名前・倍率とも変更可
- 商品枠は最大20（10〜20品での運用想定）

## 再生成・検証

```bash
pip install openpyxl
python build_tool.py                       # xlsxを生成（サンプルデータ入り）
python <xlsxスキルのrecalc.py> TOHO新宿_コンセッション準備数ツール.xlsx   # 数式の再計算(LibreOffice)
python verify_tool.py TOHO新宿_コンセッション準備数ツール.xlsx 7          # 期待値との突合(7/3/1日)
```
