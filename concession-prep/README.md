# コンセッション事前準備数ツール（雛形 v2）

TOHOシネマズ新宿のコンセッション（飲食売店）向けに、ピーク前の商品準備数（作る数）を
過去の購買率から算出するExcelツールの雛形です。

- 成果物: `TOHO新宿_コンセッション準備数ツール.xlsx`
- 生成スクリプト: `build_tool.py`（openpyxl。レイアウトや商品サンプルを変えて再生成できます）
- サンプルデータ: `sample_data.py`（seed固定。build/verifyで共有）
- 検証スクリプト: `verify_tool.py`（Pythonで独立に再計算した期待値と、Excelの計算結果を突合）

## シート構成

| シート | 役割 | 主な操作者 |
|---|---|---|
| 使い方 | 3ステップの利用ガイド・凡例・注意点 | 全員 |
| 準備数計算 | 参照期間 × 時間帯の購買率 × ピーク動員数 × 倍率 →「👉 作る数」 | 社員（確認: スタッフ） |
| 印刷用 | A4縦1枚の仕込み指示書。準備数計算と自動連動、チェック欄付き | 現場 |
| 日別データ | 直近7日の日付・動員数（1日計＋朝/昼/夕方/夜は任意）を入力 | 社員 |
| CSV貼付 | 集計ソフトのCSV貼り付け場所（商品名チェック・時間帯判定付き） | 社員 |

## 計算ロジック

- 購買率 ＝ 参照期間（の選んだ時間帯）の販売数 ÷ 動員数
- 作る数 ＝ ピーク動員数 × 購買率 × 倍率（小数点以下切り上げ）
  - ピーク動員数 ＝ これから準備する回（例: 1時間後のピークの回）の合計動員数
- 参照期間: 直近7日間 / 直近3日間 / 昨日
- 時間帯: 1日全体 / 朝 / 昼 / 夕方 / 夜
  - CSVのD列の時刻（例 13:05）または時間帯名から自動判定（区切り時刻はCSV貼付シートで変更可）
  - CSVに時間帯情報が無い場合は「1日全体」へ自動フォールバック（警告表示）
- 商品枠は最大20（10〜20品での運用想定）、CSV貼付は最大2000行

## 入力ミスへのガード

- 動員数が未入力の日は、販売数・動員数の両方を計算から除外（購買率の歪みを防止）
- 動員数がゼロのときは購買率に「要確認」、作る数に「—」を表示（0個と誤読させない）
- 動員数未入力日・CSVデータ欠落・時間帯フォールバックは計算シート上部に赤字で警告
- 日別データに日付ごとの「CSV取込チェック」行（✔ / ⚠なし）
- 時間帯別動員の合計が1日計と合わない列は色でハイライト
- 時刻付き日付でも集計できるよう、SUMIFSは日付範囲条件（当日以上・翌日未満）で照合
- 未登録商品カウントはチェック列に依存しない独立式
- 入力規則のエラーアラート有効（リスト外・範囲外の値をブロック）

## 再生成・検証

```bash
pip install openpyxl
python build_tool.py                       # xlsxを生成（サンプルデータ入り）
python <xlsxスキルのrecalc.py> TOHO新宿_コンセッション準備数ツール.xlsx   # 数式の再計算(LibreOffice)
python verify_tool.py TOHO新宿_コンセッション準備数ツール.xlsx 7 昼       # 期待値との突合(期間7/3/1×時間帯)
```
