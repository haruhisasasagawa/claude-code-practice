# コンセッション事前準備数ツール（v5.1）

TOHOシネマズ新宿のコンセッション（飲食売店）向けに、ピーク前の商品準備数（作る数）を
過去の購買率から算出するExcelツール。TOHOの営業週（金曜開始）に対応。
v5で時間帯係数の較正シート（係数算出・係数貼付①〜④）を本体ワークブックに統合。
v5.1で「商品別の波」（商品ごとの時間帯パターンの実測と作る数への適用）を追加。

- 成果物: `TOHO新宿_コンセッション準備数ツール.xlsx`（未入力テンプレート・全機能入り1ブック）
- 生成スクリプト: `build_tool.py`（openpyxl。CSVを渡すと入力済みサンプルも生成可能）
- 較正モジュール: `build_calib.py`（係数算出・係数貼付シートを本体へ追加する。単体実行はしない）
- 検証スクリプト: `verify_tool.py`（CSVからPythonで独立集計した期待値とExcelの計算結果を突合）

※ 実売上CSV・入力済みサンプルは店舗の実数を含むためリポジトリには含めない。

## シート構成

| シート | 役割 |
|---|---|
| 使い方 | 3ステップの利用ガイド・凡例・注意点・較正の手順 |
| 準備数計算 | 参照期間(A/B)の購買率 × ピーク動員数 × 時間帯係数 × 調整倍率 →「👉 作る数」 |
| 印刷用 | A4縦1枚の仕込み指示書（自動連動・チェック欄・記入欄付き） |
| 期間データ | 期間A（直近 金土日）・期間B（前週 金〜木）の日付・動員数入力と商品別販売集計 |
| CSV貼付A / B | 本社集計「売上・在庫・原価」CSVを全選択コピー→オレンジのA4セルへ「値の貼り付け」するだけのシート |
| 係数算出 | 金曜4週分のMSO明細から時間帯5段階の係数候補を実測算出（月1回・任意） |
| 商品別の波 | 登録商品ごとの時間帯パターン（構成比・商品別係数・判定）を自動算出 |
| 係数貼付①〜④ | MSO商品CSV（注文明細・金曜1日分）を1週ずつ貼る較正用の貼り付けシート |

## 計算ロジック

- 購買率 ＝ 参照期間の販売数（CSVの「売上数」列をSUMIF集計） ÷ 参照期間の動員数合計
- 作る数 ＝ ピーク動員数 × 購買率 × 時間帯係数 × 調整倍率（小数点以下切り上げ）
  - ピーク動員数 ＝ これから準備する回（例: 1時間後のピークの回）の合計動員数
  - 時間帯係数 ＝ 5段階の時間帯プリセット（朝一〜11時/昼ピーク11〜15時/夕方15〜18時/夜ピーク18〜21時/レイト21時〜）＋平常。名前・時刻・係数とも編集可（最大7枠）
  - 調整倍率 ＝ その日の状況（大作初日・雨など）での上乗せ/控えめ。二段構えで両方掛かる
- 参照期間: 期間A（金土日）／期間B（金〜木）／期間平均（A+B合算10日間）をドロップダウンで切替。
  比較期間（A選択時はB、それ以外はA）の購買率を参考列に表示
- 期間の日付は貼られたCSVの「対象期間開始/終了」から自動表示（入力不要）
- 商品名: 貼られたCSVの商品名から数式で自動抽出したリストのプルダウンで選択（先出順・手入力も可）
  - ドリンク類・調味料・ＳＥＴ作品コンボ・引換券・包材は既定でプルダウン対象外（小分類名の除外リストで編集可。集計からは除外されない）
- 商品枠は最大20、CSV貼付は各期間 最大1000行

## 時間帯係数の較正（係数算出・係数貼付①〜④）

- 係数貼付①〜④に金曜4週分のMSO商品CSV（注文明細・秒単位の時刻つき・金曜1日分で出力・
  最大12,000行/シート）を1週ずつ貼ると、係数算出シートが5段階の係数候補を自動算出
  （貼った週だけで平均。4週未満でも動作）
- 係数候補 ＝ 帯の1時間あたり販売個数 ÷ 全帯平均の1時間あたり販売個数。
  時間の区切り（既定 8:00/11:00/15:00/18:00/21:00/翌2:00）は係数算出シート上で編集可
- 集計ルール: セット親・注文取消・払戻は除外して実個数を集計。複数日が混在したCSVは
  先頭の日付だけを集計して状態表示に⚠（対象日はS3で手動上書き可）。金曜以外は※表示
- 候補は「準備数計算」プリセット表の右の実測候補列（K4:K8）にも自動表示。
  採用はプリセット表のJ列へ手入力（勝手に置き換えない設計）
- 誤操作ガード: 別種CSVの誤貼付・貼付位置ズレ・行削除によるヘルパー式の破損は
  各貼付シートの正常フラグ（AD3: ヘッダー照合＋式の生存数チェック）で検知し、
  その週を集計から自動除外して状態表示と係数算出のB23に⚠。12,000行超の貼付も⚠。
  閉店時刻は 26:00 等の24時間超え表記でも翌2:00として解釈（MOD正規化）

## 商品別の波（商品ごとの時間帯係数）

- 「商品別の波」シートが、登録20商品それぞれについて帯別の販売個数（係数貼付①〜④の
  有効週合計・非表示のP〜T列）→構成比（1日の売れ方の推移をデータバーで可視化）→
  商品別係数（帯の1hあたり個数÷その商品の1日平均ペース・0.05刻み）を自動算出
- 準備数計算の「⑤ 商品別の波」を『使う』（既定）にすると、作る数の係数が全体の
  時間帯係数から商品ごとの実測係数に置き換わる。適用値は「商品係数」列に表示（—＝全体係数）
- 自動フォールバック: 合計個数がしきい値（既定30個・商品別の波!D3で編集可）未満の商品は
  「⚠少データ」、MSO側に同名が無い商品は「該当なし」、選択した帯の個数が0の商品も
  全体の時間帯係数で計算（作る数が無警告で0になるのを防ぐ）。
  時間帯プリセットが①〜⑤以外（平常など）のときも全体係数
- 帯の対応はプリセット名の先頭の①〜⑤マークがキー（行位置に依存しないため表の
  並べ替えに頑健）。改名時もマークは残すこと（消すとその帯は全体係数になり赤警告）
- 商品名の照合は完全一致（実データでは登録20商品すべてMSO側と一致を確認済み）。
  帯の区切り・帯の長さは係数算出シートの設定に連動（区切りが逆転した帯は自動除外）

## 入力ミスへのガード

- CSVの日数チェック（期間A=3日/期間B=7日想定、✔／⚠）、金曜開始チェック、別期間行の混在検知、
  古いデータの検知（終了日が9日以上前なら⚠）
- 計算シート上部に赤字警告（印刷用にも連動）: CSV未貼付 / 期間不一致 / 動員数不足 /
  商品名重複 / ピーク動員数未入力 / 適用倍率0%
- 動員数ゼロのときは購買率に「要確認」、作る数に「—」を表示
- 商品名の重複は赤ハイライト。プリセット名が不正でも倍率は×100%にフォールバック
- 入力規則のエラーアラート有効（動員数の数値限定を含む）。全シートA4印刷設定済み

## 再生成・検証

```bash
pip install openpyxl
python build_tool.py                                        # 未入力テンプレート
python build_tool.py --out サンプル.xlsx \
    --csv-a 期間A.csv --csv-b 期間B.csv --select A \
    --att-a 9000,13000,12000 --att-b 8500,12500,11500,6000,6500,7000,6000 \
    --peak 1200 --preset "② 昼ピーク（11〜15時）" --adjust 1.1 \
    --mso1 金曜1週目MSO.csv                                  # 入力済みサンプル(較正データ込み)
python <xlsxスキルのrecalc.py> <xlsx>                        # 数式の再計算(LibreOffice)
python build_tool.py --show-notes <xlsx>                    # 貼り付け案内メモの常時表示化(最後に実行)
python verify_tool.py <xlsx> --template                      # テンプレートの検証
python verify_tool.py <xlsx> --csv-a ... --csv-b ... --select A --att-a ... --att-b ... \
    --peak 1200 --mult 1.2 --adjust 1.1 --mso1 金曜1週目MSO.csv --band 2
```
