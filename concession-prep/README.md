# コンセッション事前準備数ツール（v4）

TOHOシネマズ新宿のコンセッション（飲食売店）向けに、ピーク前の商品準備数（作る数）を
過去の購買率から算出するExcelツール。TOHOの営業週（金曜開始）に対応。

- 成果物: `TOHO新宿_コンセッション準備数ツール.xlsx`（未入力テンプレート）
- 生成スクリプト: `build_tool.py`（openpyxl。CSVを渡すと入力済みサンプルも生成可能）
- 検証スクリプト: `verify_tool.py`（CSVからPythonで独立集計した期待値とExcelの計算結果を突合）

※ 実売上CSV・入力済みサンプルは店舗の実数を含むためリポジトリには含めない。

## シート構成

| シート | 役割 |
|---|---|
| 使い方 | 3ステップの利用ガイド・凡例・注意点 |
| 準備数計算 | 参照期間(A/B)の購買率 × ピーク動員数 × 時間帯係数 × 調整倍率 →「👉 作る数」 |
| 印刷用 | A4縦1枚の仕込み指示書（自動連動・チェック欄・記入欄付き） |
| 期間データ | 期間A（直近 金土日）・期間B（前週 金〜木）の日付・動員数入力と商品別販売集計 |
| CSV貼付A / B | 本社集計「売上・在庫・原価」CSV（34列・cp932）をそのまま貼るだけのシート |

## 計算ロジック

- 購買率 ＝ 参照期間の販売数（CSVの「売上数」列をSUMIF集計） ÷ 参照期間の動員数合計
- 作る数 ＝ ピーク動員数 × 購買率 × 時間帯係数 × 調整倍率（小数点以下切り上げ）
  - ピーク動員数 ＝ これから準備する回（例: 1時間後のピークの回）の合計動員数
  - 時間帯係数 ＝ 5段階の時間帯プリセット（朝一〜11時/昼ピーク11〜15時/夕方15〜18時/夜ピーク18〜21時/レイト21時〜）＋平常。名前・時刻・係数とも編集可（最大7枠）
  - 調整倍率 ＝ その日の状況（大作初日・雨など）での上乗せ/控えめ。二段構えで両方掛かる
- 参照期間: 期間A（金土日）／期間B（金〜木）をドロップダウンで切替。もう一方の期間の購買率を参考列に表示
- 期間の日付は貼られたCSVの「対象期間開始/終了」から自動表示（入力不要）
- 商品名: 貼られたCSVの商品名から数式で自動抽出したリストのプルダウンで選択（先出順・手入力も可）
  - ドリンク類・調味料・ＳＥＴ作品コンボ・引換券・包材は既定でプルダウン対象外（小分類名の除外リストで編集可。集計からは除外されない）
- 商品枠は最大20、CSV貼付は各期間 最大1000行
- 時間帯別の購買率（朝昼夕夜で率を分ける）はCSVに時刻情報が無いため今後の課題

## 入力ミスへのガード

- CSVの日数チェック（期間A=3日/期間B=7日想定、✔／⚠）、金曜開始チェック、別期間行の混在検知
- 計算シート上部に赤字警告（印刷用にも連動）: CSV未貼付 / 期間不一致 / 動員数不足 /
  商品名重複 / ピーク動員数未入力 / 適用倍率0%
- 動員数ゼロのときは購買率に「要確認」、作る数に「—」を表示
- 商品名の重複は赤ハイライト。プリセット名が不正でも倍率は×100%にフォールバック
- 入力規則のエラーアラート有効（動員数の数値限定を含む）。全シートA4印刷設定済み

## 再生成・検証

```bash
pip install openpyxl
python build_tool.py                                        # 未入力テンプレート
python build_tool.py --out サンプル.xlsx \
    --csv-a 期間A.csv --csv-b 期間B.csv --select A \
    --att-a 9000,13000,12000 --att-b 8500,12500,11500,6000,6500,7000,6000 \
    --peak 1200 --preset 昼ピーク --adjust 1.1               # 入力済みサンプル
python <xlsxスキルのrecalc.py> <xlsx>                        # 数式の再計算(LibreOffice)
python verify_tool.py <xlsx> --template                      # テンプレートの検証
python verify_tool.py <xlsx> --csv-a ... --csv-b ... --select A --att-a ... --att-b ... --peak 1200 --mult 1.2 --adjust 1.1
```
