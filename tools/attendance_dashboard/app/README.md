# 勤務実績ダッシュボード（HTML版）

Excel版（`../build_dashboard.py` が作るブック）と同じ集計・同じ画面を、ブラウザだけで動く1つのHTMLファイルにしたものです。
マクロもサーバーも不要で、`dist/勤務実績ダッシュボード.html` をダブルクリックすれば開きます（Edge / Chrome 推奨）。

## 使い方

1. シェアフルシフトから月初〜月末の1ヶ月分ずつシフトCSVを出力します（最大6ヶ月）。
2. 「使い方」タブの枠にCSVをまとめてドラッグ＆ドロップ（または「ファイルを選ぶ」）。
   月を自動で読み取り、古い月から順に並べます。読み込み状況の表が全部「OK」なら完了です。
3. 「ダッシュボード」タブでスタッフを選ぶと、Excel版と同じA4縦1枚のページが出ます。「印刷」でそのままPDFにできます。
   「全員分を印刷」で1人1ページのPDFも作れます。
4. 「スタッフ一覧」「全体サマリー」は列見出しクリックで並べ替え、所属・判定で絞り込みができます。
5. 判定の基準・職種・所属は「設定」タブ、祝日・繁忙日は「祝日・繁忙日」タブで変えられます。
   「設定を書き出す」で保存したJSONを他の劇場で「設定を読み込む」と、同じ基準をそろえられます。

## 個人情報の扱い

- 読み込んだCSVの内容はブラウザのメモリ上だけで計算し、どこにも送信・保存しません。ページを閉じると消えます。
- ブラウザに保存されるのは「設定」と「祝日・繁忙日」の一覧だけです（localStorage）。
- 印刷・PDFには個人の勤務情報が入ります。取り扱いにご注意ください。

## Excel版との関係

- 数値・表示文字列はExcel版と同一になるように作り、LibreOfficeで再計算したExcelブックの全セルと突き合わせるテスト（下記）で確認しています。
- Excel版にあった上限（1ヶ月6,000行・400名・一覧12件・出勤していない繁忙日24件・連休6件）は、印刷するA4ページの表示件数としては同じですが、集計は全行・全員で行い、画面では「すべて表示」できます。
- 同じ名前のスタッフが2人いる場合、Excel版と同じく名前順で先の人が表示されます（従業員番号で区別はしていません）。

## 開発

```
app/
  src/engine/   計算（csv → calc → roster → view の順に読み込む。DOMに触らない）
  src/ui/       画面（index.html / style.css / charts.js / app.js）
  build.py      src を1つの dist/勤務実績ダッシュボード.html にまとめる
  test/         テスト
```

- ビルド: `python3 build.py`
- 単体テスト: `node test/unit_ingest.js` / `node test/unit_roster.js` / `node test/unit_view.js`
- 突き合わせテスト（Excelブックの計算結果との比較）:
  - `node test/parity.js --extra` … リポジトリ内の架空データ（`test/fixtures/`）だけで動きます。
  - `node test/parity.js --all` … 6ヶ月分の架空サンプルCSVと、それをExcel版に通してLibreOfficeで再計算した結果（JSON）が必要です。
    置き場所は `test/parity.local.json`（git管理外）か環境変数 `AE_GOLDEN_DIR` / `AE_SAMPLE_DIR` で指定します。無い場合はその旨を表示して終了します。
  - `--private` … 実データで作った結果との比較。実データはリポジトリに入れません。
- 画面の確認: `python3 test/ui_check.py --csv-dir <サンプルCSVのフォルダ> --out <出力先>`（Playwright + Chromium。
  通信が一切無いこと、ダッシュボードがA4縦1枚に印刷されることなどを確認し、各タブのスクリーンショットを保存します）

テスト用データはすべて架空の名前・従業員番号です。実在のスタッフのデータをリポジトリに入れないでください。
