# 勤務実績ダッシュボード（TOHOシネマズ新宿）

シェアフルシフトから出力した月次シフトCSVを貼り付けるだけで、アルバイトスタッフごとの
出勤日数・出勤率・当欠率（当日欠勤率）・勤務時間などを集計して表示する Excel ブックです。
契約更新面談で客観的な勤務実績を示す目的で作成しました。マクロは使っていません。

## ファイル

| ファイル | 内容 |
|---|---|
| `勤務実績ダッシュボード_テンプレート.xlsx` | 空のブック（CSV未貼付）。個人情報を含むため、データ入りのファイルはリポジトリに置かず別途配布 |
| `build_dashboard.py` | 上記ブックを生成するスクリプト（openpyxl） |
| `inject_values.py` | LibreOffice で再計算した結果を生成ブックにキャッシュ値として埋め込む（保護ビューやプレビューでも数値が見えるようにする） |

## ブックの構成

| シート | 役割 |
|---|---|
| 使い方 | 手順・貼付状況・指標の定義・注意事項 |
| ダッシュボード | スタッフを選ぶと KPI タイル、出勤率リング、月別推移、職種別構成、曜日別、全体比較、月別サマリーを表示（A4縦1枚で印刷可） |
| PDF出力 | ダッシュボードで選んだスタッフの数字・グラフ・月別の実績・欠勤と当日時間変更の一覧・繁忙日の出勤状況をA4縦1枚にした面談用ページ。Excel の「エクスポート → PDF/XPS」でそのまま PDF になる |
| スタッフ一覧 | 全員の半年集計・順位・所属別集計・出勤率ワースト10 |
| CSV_1〜CSV_6 | 月次CSVの貼り付け先（A1にヘッダー行ごと貼り付け） |
| 設定 | 判定の基準値、参考値扱いの日数、深夜時間帯、職種/所属の表示名 |
| 祝日・繁忙日 | 土日以外で「繁忙日」として数える日付の一覧（祝日・GW・お盆・年末年始を初期登録。追加・削除可） |
| 名簿・DB計算・計算1〜6 | 集計エンジン（非表示。編集不要） |

## 他の劇場で使うとき

「設定」シートだけ変更すれば使えます: 劇場名（B1）、判定の基準（B3〜B5）、深夜の時間帯（B7〜B8）、
当欠率のアラート基準（B6）、職種の区分（A13〜B32、最大20件、CSVの「募集シフトの職種」の値）、所属の一覧（A38〜B57、最大20件、CSVの「応募者の職種」の値）。
さらに「祝日・繁忙日」シートで、土日以外に繁忙日として数える日付を編集できます。
CSVの列名が同じであれば数式の変更は不要です。

## 指標の定義

- **出勤日数**: ステータスが「確定」系で勤務種別が勤務(1)のシフトがある日数（人×日で重複除外）
- **欠勤日数**: 確定していたシフトが、シフト当日に「休み」(勤務種別4) へ変更された日数（更新時間を JST に直してシフト日と比較）
- **確定シフト日数** = 出勤日数 + 欠勤日数（事前に休みへ変更した日は含めない）
- **出勤率** = 出勤日数 ÷ 確定シフト日数、**当欠率（当日欠勤率）** = 欠勤日数 ÷ 確定シフト日数。設定の基準（既定5%）以上でダッシュボードに警告、スタッフ一覧に赤い塗り
- **勤務時間**: 変更後の開始〜終了時間から休憩を引いたシフト上の時間
- **土日祝出勤率**: 土日・祝日・繁忙日に出勤した日数 ÷ 出勤日数。土日は WEEKDAY で自動判定、それ以外は「祝日・繁忙日」シートの日付と突き合わせ（国民の祝日＋振替休日＋国民の休日を 2025〜2031 年分と、GW・お盆・年末年始を初期登録）
- **繁忙日の出勤状況**: 「祝日・繁忙日」シートに登録した日のうち、対象期間（貼付済みの月の初日〜末日）に入る日を、**出勤／当日欠勤／事前に休み・却下／シフト未エントリー**の4区分で数える。未エントリー＝その日のシフトに1件も応募していない日（店舗側の募集が無かった日も含む）。区分ごとの件数と、未エントリーの日付一覧（最大15日）をダッシュボード下部と「PDF出力」に表示。土日はこの4区分の対象外（土日込みの割合は土日祝出勤率で見る）
- **当日遅出／当日早退**: 確定した勤務シフトが、シフト当日に「変更後の開始時間」を募集の開始より遅く（当日遅出）／「変更後の終了時間」を募集の終了より早く（当日早退）変更された日数。シフト上の変更であり打刻の遅刻・早退ではない。**当日遅出率／当日早退率** = 各日数 ÷ 確定シフト日数。ダッシュボードの「休み・時間変更のタイミング」と一覧、スタッフ一覧に表示

## 生成方法

```bash
pip install openpyxl
python build_dashboard.py 勤務実績ダッシュボード.xlsx --csv 2026-08.csv            # 8月分を貼付済みで生成
python build_dashboard.py out.xlsx --csv 8月.csv 9月.csv - 11月.csv                 # "-" は空の月
python build_dashboard.py out.xlsx --maxrows 8000                                  # 1ヶ月あたりの上限行数を変更
```

上限は 1ヶ月 6,000 行・半年 400 名（`--maxrows`, `MAXSTAFF` で変更可）。

生成直後のブックには計算結果（キャッシュ値）が入っておらず、Excel で開いたときに全再計算されます。
配布用には、LibreOffice で再計算したコピーから値を埋め込んでおくと、保護ビューやプレビューでも数値が表示されます:

```bash
cp out.xlsx recalc.xlsx && soffice --headless ... (xlsx スキルの recalc.py で再計算)
python inject_values.py out.xlsx recalc.xlsx 勤務実績ダッシュボード.xlsx
```

`share_formulas.py`（縦に並ぶ同じ数式を OOXML の共有数式に書き換えて容量を 1/3 にする）は、Excel で開くと「名簿」「計算1〜6」の数式が修復で削除されるため使わない。LibreOffice は問題なく開くが Excel が受け付けない。テンプレートは約12MB、6ヶ月分を貼ると約16MB になる。

## 検証

- `openpyxl` で書いた数式を LibreOffice で再計算し、pandas で独立に計算した値と全員分を突合して一致を確認済み
- 貼り付けの変種（全て文字列／列順シャッフル／ヘッダー無し／未貼付／飛び月／行数超過／従業員番号の桁違い）でもエラーが出ないことを確認済み
