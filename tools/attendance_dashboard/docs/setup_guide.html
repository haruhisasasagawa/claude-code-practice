所要10〜15分。原本（テンプレート）と、新宿の設定・8月データが入った見本を本文に添付します。各劇場は必ず原本をコピーし、自劇場用にセットアップしてご利用ください。マクロは使っていません（Excel 2016以降／Microsoft 365）。

手順 ― 上から順に1回だけ

SETUP 1原本をコピーして劇場名を入れる― 「設定」B1セル

「勤務実績ダッシュボード_◯◯.xlsx」のように劇場名を付けて保存し、「設定」B1（黄色セル）に劇場名を入力します。ダッシュボードの見出しに出ます。

変更してよいのは黄色セルと CSV_1〜6 だけ。非表示の計算用シートは表示・編集しないでください。ダッシュボードは誤操作防止のため保護しています（パスワードなし）。

SETUP 2使うCSVの出力条件を確認する
  • 使うのはシェアフルシフトのシフトCSV1種類だけです（打刻データは使いません）。
  • 期間は月初〜月末の1ヶ月分で1本ずつ出力（例：8/1〜8/31）。半年分で6本になります。
  • ヘッダー行（1行目の列名）を含めて出力し、列名は変えないでください。列の順番は変わっても動きます。
  • 1ヶ月6,000行・半年400名まで。超える場合はご連絡ください。
SETUP 3職種・所属・祝日を自劇場に合わせる― 「設定」A13〜B32／A38〜B57、「祝日・繁忙日」シート
  • 職種の区分＝CSVのL列「募集シフトの職種」の値（例：01ボックス、02コンセ）。セクション割りに合わせて最大20件。表に無い値は自動で「その他」に。使わない行は空欄のまま。
  • 所属の一覧＝CSVのR列「応募者の職種」の値。最大20件。所属別集計と「同所属平均」に使います。CSVの値と完全一致で入力してください。
  • 祝日・繁忙日＝土日祝出勤率で使う日付。土曜・日曜は自動なので、登録するのは平日の祝日と、出勤してほしい繁忙日だけです。
  • 国民の祝日 2025〜2032年分と、GW・お盆・年末年始は登録済み。地域のイベント日があれば足し、不要な行は削除できます。
  • CSVを貼ると右のC列に貼付データでの行数が出ます。「※ 貼付データに無い値です」は表記違いなので、CSVの値をコピーして入れ直します。
SETUP 4判定とアラートの基準を確認する― 「設定」B3〜B6

総合判定は出勤率だけで決まります。既定は ◎良好＝95%以上／△注意＝90%以上／✕要改善＝90%未満、確定シフト日数が20日未満の人は判定を出さず「参考値」です。当欠率のアラート＝B6（既定 5%）。これ以上のスタッフに赤い警告行と赤い塗りが出ます。

試験運用中はエリアで同じ基準に統一してください。途中で変えると劇場間・期間間の比較ができなくなります。

SETUP 5最初の1ヶ月を貼って表示を確認する― 「CSV_1」A1セル
  • CSVをExcelで開き、全選択（Ctrl+A）→コピー→「CSV_1」のA1セルを選んで貼り付け（ヘッダー行ごと）。
  • 「使い方」シートの貼付状況が「2026年8月／OK」と出れば成功です。※印が出たら次ページの表で対処します。
  • 「設定」C列に行数が出ているか（SETUP 3）、「ダッシュボード」でスタッフを選んで数字とグラフが出るかを確認します。
SETUP 6印刷とPDFを確認する（任意）

ダッシュボードはA4縦1枚、全体サマリーはA4横1枚、スタッフ一覧は名前がある行まで印刷されます。Ctrl+P で白紙ページが出ないことを一度確認。PDFは ファイル → エクスポート → PDF/XPS。
