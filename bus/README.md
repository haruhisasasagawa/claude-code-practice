# 京王バス リアルタイムマップ

京王バスが「今どこを走っているか」を地図上でリアルタイムに確認できるWebアプリです。
新宿駅西口 ⇔ 新山通り(宿41系統など)の利用を想定し、初期状態では宿41で絞り込み、
2つのバス停を地図上にマークします。

## 機能

- 🚌 運行中のバスの現在位置を地図上に表示(約15秒ごとに自動更新)
- 🧭 バスの進行方向を矢印で表示
- 🕐 各バスをタップすると「系統・行き先・始発地の発車時刻(=どの時刻表の便か)・遅れ」を表示
- 🔍 系統名(宿41 など)での絞り込み
- 🚏 「新宿駅西口」「新山通り」バス停の位置をマーク
- 遅延情報(TripUpdate)があれば「約◯分遅れ」を表示

## データソース

- [公共交通オープンデータセンター(ODPT)](https://www.odpt.org/) が提供する
  京王バスの GTFS / GTFSリアルタイムデータ
  - 車両位置: `https://api.odpt.org/api/v4/gtfs/realtime/odpt_KeioBus_AllLines_vehicle`
  - 遅延情報: `https://api.odpt.org/api/v4/gtfs/realtime/odpt_KeioBus_AllLines_trip_update`
  - 時刻表(静的GTFS): `https://api.odpt.org/api/v4/files/odpt/KeioBus/AllLines.zip`
- 地図タイル: [OpenStreetMap](https://www.openstreetmap.org/)

URLが変更された場合は、アプリの「⚙ 設定 → 詳細設定」から変更できます。
最新のURLは [ODPTデータカタログの京王バスのページ](https://ckan.odpt.org/dataset/odpt_keio_bus_all_lines) で確認してください。

## 使い方

### 1. ODPTのアクセストークンを取得する(無料)

1. [developer.odpt.org](https://developer.odpt.org/) で開発者登録(無料)をする
2. ログイン後、「アクセストークンの確認・追加」からトークンを発行する

### 2. アプリを開く

**GitHub Pages で公開する場合(推奨):**
リポジトリの Settings → Pages でブランチを公開すると、
`https://<ユーザー名>.github.io/claude-code-practice/bus/` で開けます。
スマホのホーム画面に追加すればアプリのように使えます。

**ローカルで動かす場合:**
`file://` で直接開くとブラウザの制限で動きません。リポジトリ直下で

```bash
python3 -m http.server 8000
```

を実行し、`http://localhost:8000/bus/` を開いてください。

### 3. 初回設定

初回に設定画面が開くので、取得したアクセストークンを貼り付けて「保存して開始」を押します。
トークンはブラウザの localStorage にのみ保存され、外部には送信されません(ODPTのAPI呼び出しを除く)。

初回は時刻表データ(GTFS、数十MB)をダウンロードして解析するため少し時間がかかります。
以後24時間はブラウザ内(IndexedDB)にキャッシュされます。

## トラブルシューティング

- **「取得エラー」が出る**
  - トークンの誤りが最も多い原因です。設定画面で確認してください。
  - `file://` で開いている場合は上記のとおりローカルサーバー経由で開いてください。
  - それでも失敗する場合、ブラウザの開発者ツール(Console)に CORS エラーが出ていないか
    確認してください。CORS でブロックされる場合は、CORS を許可する簡単な中継サーバー
    (プロキシ)を経由する必要があります。設定画面の「詳細設定」で各URLを
    プロキシ経由のURLに差し替えられます。
- **系統名が `route_...` のようなIDで表示される**
  - 時刻表データ(GTFS)の取得に失敗しています。ページを再読み込みしてください。
- **バスが1台も表示されない**
  - 深夜など運行時間外の可能性があります。「すべて表示」を押して他系統も出ないか確認してください。

## 出典・注意事項

本アプリが利用する公共交通データは、[公共交通オープンデータセンター](https://www.odpt.org/)において提供されるものです。
公共交通事業者により提供されたデータを元にしていますが、必ずしも正確・完全なものとは限りません。
本アプリの表示内容について、公共交通事業者への直接の問い合わせは行わないでください。
