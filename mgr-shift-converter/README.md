# MGRシフト → シフトライン人数確認表

`build.py` は、MGRシフト表（月シート＋マスタ）から「シフトライン人数確認表」のExcelを生成します。
生成したファイルは、翌月以降 MGRシフト表の月シートを「MGR貼付」シートへ値貼り付けするだけで更新できます。

```
python build.py <MGRシフト.xlsx> <月シート名> <出力.xlsx>
```

生成済み: `MGRシフトライン_2026-12.xlsx`（2026年12月分を転記済み）

| シート | 内容 |
|---|---|
| シフトライン | 日を選ぶと、その日の出勤者を出勤時刻順に30分単位のバーで表示。30分ごとの人数、出勤計、必要人数、行事つき |
| 月間 | 日×30分の人数一覧（色の濃さ＝人数、基準人数を下回ると赤）。出勤者数・必要人数・差・行事つき |
| 社員別 | 出勤日数、早番/中番/遅番/夜番の日数、勤務時間、休の日数 |
| 設定 | 表示開始時刻、30分ごとの基準人数、使い方 |
| MGR貼付 / MGRマスタ | 貼り付け先（値貼り付け） |
| 計算 | 自動計算用（編集不要） |

## 原本（テンプレート）

`make_master.py` は、運用で安定した版（データ入り）から月データを空にした原本を作ります。
x14 形式の条件付き書式・入力規則・図形を保つため、openpyxl を通さず xlsx 内の XML を直接編集します。

```
python make_master.py <安定版.xlsx> <原本.xlsx>
```

生成済み: `MGRシフトライン_原本.xlsx`

毎月の使い方: 原本をコピー → 「MGR貼付」の D3 に月初の日付を入力 → 記号・行事・必要人数を入力（またはMGRシフト表から値貼り付け）。
